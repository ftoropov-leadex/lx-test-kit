lx-test-kit DSL Glossary

Two assertion DSL layers, both backed by AssertJ AbstractAssert — every public method is auto-stepped by AllureAspectJ via LTW. Splunk await methods (SplunkSupport / SplunkClient) are included because they form the pre-assertion pipeline.

#API Response DSL

io.leadex.aqa.testsupport.assertions

#Response-level

DSL artifact Which Java-class calls Data format to input Example
.assertThat() ApiResponseAssert — Static entry point for the API response assertion chain. ApiResponse<T> ApiResponseAssert.assertThat(response)
.hasStatus() AbstractApiResponseAssert — Asserts HTTP status code equals the expected value. int ApiResponseAssert.assertThat(response).hasStatus(200)
.body() AbstractApiResponseAssert — Parses the raw JSON response body and opens a BodyAssert scope via consumer lambda. The raw body is parsed once and cached. Consumer<BodyAssert> ApiResponseAssert.assertThat(response).hasStatus(200).body(b -> b.field("id", f -> f.isPresent()))

#Body-level (.body(b → …) scope)

DSL artifact Which Java-class calls Data format to input Example
.at() BodyAssert — Navigates to an array element by index, opens a nested BodyAssert scope. Requires the body to be a non-empty array at that index. int + Consumer<BodyAssert> .body(b -> b.at(2, el -> el.field("name", f -> f.hasValue("third"))))
.first() BodyAssert — Shorthand for .at(0, …). Navigates to the first array element, opens a nested BodyAssert scope. Consumer<BodyAssert> .body(b -> b.first(el -> el.field("id", f -> f.isNotBlank())))
.field() BodyAssert — Navigates to a field by dot-notation path (e.g. "args.suite", "items.0.name"), opens a FieldAssert scope. Never throws on missing nodes — the terminal assertion decides. String + Consumer<FieldAssert> .body(b -> b.field("args.suite", f -> f.hasValue("integration")))
.hasField() BodyAssert — Asserts a field exists and is non-null at the given dot-notation path. Structural check without value comparison. String .body(b -> b.hasField("data.items.0.name"))
.isNotEmpty() BodyAssert — Asserts the body is a non-empty JSON array. Fails if not an array or if empty. — .body(b -> b.isNotEmpty().first(el -> …))
.matchesSchema() BodyAssert — Validates the full original response JSON against a JSON Schema file on the classpath. Not available on FieldAssert. String — classpath-relative path .body(b -> b.matchesSchema("schemas/postman-echo-get.schema.json"))
.matchesSnapshot() BodyAssert — Validates the full original response JSON against a golden-file snapshot by name. Not available on FieldAssert. String — snapshot name .body(b -> b.matchesSnapshot("postman-echo-get"))

#Field-level (.field(path, f → …) scope)

DSL artifact Which Java-class calls Data format to input Example
.isPresent() FieldAssert — Asserts the field exists and is non-null. Fails on missing node or JSON null. — .field("orderId", f -> f.isPresent())
.hasValue() FieldAssert — Asserts the field equals an expected value. Type-aware extraction: String, Integer/int, Long, Double, Boolean, BigDecimal (scale-insensitive — matches any numeric node). Object .field("status", f -> f.hasValue("created")) / .field("count", f -> f.hasValue(3))
.isNotBlank() FieldAssert — Asserts the field is a non-blank string. Fails on missing, null, empty, or whitespace-only. — .field("message", f -> f.isNotBlank())
.isNotEmpty() FieldAssert — Asserts the field is non-empty. For arrays: size > 0. For strings: length > 0. Fails on missing or null. — .field("tags", f -> f.isNotEmpty())

#Dot-notation path rules

  • Split on literal . only — "args.suite", "items.0.name". Brackets ([]) are not supported.
  • Array index navigation: when a path segment is all digits (e.g. "0") and the current node is an array, the navigator resolves it as a positional index. "items.0.name" navigates into the first element of the items array.
  • Non-numeric segments are treated as JSON object keys.
// Given response body:
// { "items": [{"name":"apple"}, {"name":"banana"}] }

.body(b -> b
    .field("items.0.name", f -> f.hasValue("apple"))   // "0" resolves as array index 0
    .field("items.1.name", f -> f.hasValue("banana"))   // "1" resolves as array index 1
    .field("items.name",   f -> f.isPresent())           // "name" is non-numeric → object key lookup
)

#Chain invariants

  • .hasStatus() must be called before .body() when status is relevant.
  • .body() always requires a lambda — there is no short-form .body().field(…). The lambda scope is what allows AllureAspectJ to wrap it as a collapsible nesting step in the Allure report HTML. Without nesting, a flat list of assertion steps makes it hard to tell which value is the field path versus the expected value.
  • .field(dotPath, …) never throws on missing nodes — only terminal assertions (hasValue, isNotBlank, etc.) fail.
  • .first() / .at() require a non-empty array — guard with .isNotEmpty().
  • .matchesSchema() / .matchesSnapshot() always validate the full original response body, regardless of navigation depth.
  • Assertion chain must remain linear — no branching, no storing intermediate DSL objects.
// ✅ CORRECT — .body() takes a Consumer<BodyAssert> lambda (b → …)
ApiResponseAssert.assertThat(response)
    .hasStatus(200)
    .body(b -> b                          // ← lambda opens the nested scope
        .field("id",   f -> f.isPresent())
        .field("name", f -> f.hasValue("test")));

// ❌ INVALID — no .body() overload that returns BodyAssert directly.
//     This does not compile — .body() always requires a lambda argument.
ApiResponseAssert.assertThat(response)
    .hasStatus(200)
    .body()                              // ← compile error: missing Consumer argument
        .field("id", f -> f.isPresent());

#Data-driven tests

io.leadex.aqa.testsupport.testdata

DSL artifact Which Java-class calls Data format to input Example
.from() ExtractTestData — Extracts test data from a JSON array of flat-keyed objects (top-level keys are the fields a DataRow exposes; values may be any JSON, incl. nested objects/arrays) on the test classpath into a TestNG @DataProvider table — one DataRow per dataset object. A {env} token in the path resolves from FRAMEWORK_ENV (fail-fast, no fallback). Fails loud on duplicate JSON keys, non-object rows, and duplicate/blank caseName. An empty dataset returns zero rows (TestNG skips the test). Never static-import from. String classpath resource ExtractTestData.from("data/{env}/customers.json")

// data/uat/customers.json
[
  { "caseName": "active-customer",  "customerId": "9900083901", "expectedStatus": "ACTIVE"  },
  { "caseName": "blocked-customer", "customerId": "9900083902", "expectedStatus": "BLOCKED" }
]
.getString() / .getInt() / .getLong() / .getDecimal() / .getBoolean() / .getMap() / .getList() / .get() DataRow — Typed extraction of one dataset field at the use site. Missing key → IllegalStateException naming resource + row + field. Explicit JSON null → null from every getter (distinguishable from missing key). Wrong type → IllegalStateException naming expected and actual JSON type. getDecimal accepts BigDecimal and integers (widening), never double. get() is the raw escape hatch. String field name row.getString("customerId")
row.getDecimal("expectedLimit")
.caseName() / .toString() DataRow — caseName() returns the row's caseName string, or null when the key is absent. toString() renders the row as compact JSON — this is the per-invocation label in the Allure report. — row.caseName()

Dataset files live in the suite's src/test/resources/; the consumer keeps the flat test pattern — a thin @DataProvider method delegating to the loader, no test-side helper classes. The loader lives in the framework — never write dataset parsers in the consumer repo.

// src/test/resources/data/uat/customers.json
// [
//   {
//     "caseName":        "premium-active",
//     "customerId":      "9900083901",
//     "expectedStatus":  "ACTIVE",
//     "expectedLimit":   100.00,                                // decimal → row.getDecimal(...), scale preserved
//     "expectedScore":   42,                                    // integer → row.getInt(...)
//     "expectedVip":     true,                                  // boolean → row.getBoolean(...)
//     "expectedAddress": { "city": "Amman", "zip": "11183" },   // object → row.getMap(...) (deep-unmodifiable)
//     "expectedTags":    [ "premium", "sms" ],                  // array  → row.getList(...) (deep-unmodifiable)
//     "previousId":      null                                   // explicit null → null from every getter
//   },
//   {
//     "caseName":        "standard-blocked",
//     "customerId":      "9900083902",
//     "expectedStatus":  "BLOCKED",
//     "expectedLimit":   50.5,
//     "expectedScore":   7,
//     "expectedVip":     false,
//     "expectedAddress": { "city": "Irbid", "zip": "21110" },
//     "expectedTags":    [ "sms" ],
//     "previousId":      "9900083800"                           // same field, non-null here
//   }
// ]

@DataProvider(name = "customers")
public Object[][] customers() {
    return ExtractTestData.from("data/{env}/customers.json");
}

@Test(dataProvider = "customers")
public void customerMatchesDataset(DataRow row) {
    var response = call("get-customer", String.class)
            .pathParam("customerId", row.getString("customerId")).send();

    ApiResponseAssert.assertThat(response)
            .hasStatus(200)
            .body(b -> b
                    .field("status",       f -> f.hasValue(row.getString("expectedStatus")))              // string
                    .field("limit",        f -> f.hasValue(row.getDecimal("expectedLimit")))              // BigDecimal — scale-insensitive: 100.00 matches 100.0
                    .field("score",        f -> f.hasValue(row.getInt("expectedScore")))                  // integer
                    .field("vip",          f -> f.hasValue(row.getBoolean("expectedVip")))                // boolean
                    .field("address.city", f -> f.hasValue(row.getMap("expectedAddress").get("city")))    // object field → dot-path into response
                    .field("tags.0",       f -> f.hasValue(row.getList("expectedTags").get(0))));         // array field → indexed path
    // previousId (explicit null in some rows) is request-side material:
    // .bodyField("previousId", row.get("previousId")) — null is written as JSON null, not omitted
}

JSON→Java type contract — values are extracted through the DataRow accessors:

JSON value DataRow accessor
stringgetString(field)
integergetInt(field) / getLong(field) — also accepted by getDecimal (widening)
decimalgetDecimal(field) — BigDecimal, exact written scale
booleangetBoolean(field)
objectgetMap(field) (deep-unmodifiable)
arraygetList(field) (deep-unmodifiable)
explicit nullnull from every getter (get(field) is the raw escape hatch)
  • Always quote string values in dataset JSON — an unquoted 9900083901 parses as a number, and row.getString("customerId") fails at first use with an IllegalStateException naming the dataset, row, and field.
  • Decimals are extracted via row.getDecimal(...), never double/float — the loader parses decimals as BigDecimal with the exact written scale (100.00 never becomes 100.0). Assert them response-side via f.hasValue(bigDecimal) (scale-insensitive).
  • Optional caseName key: when present in a row, its value must be a non-blank, dataset-unique string — it anchors the per-invocation entry in the Allure report.
  • Nested structures are deep-unmodifiable (TestNG retry re-uses the same row); explicit nulls are preserved — passed to .bodyField(k, v) they are written as JSON null, passed to .query() / .header() / .pathParam() as the literal string "null". To omit a parameter, don't call the setter.

#Splunk DSL

io.leadex.aqa.splunk  |  io.leadex.aqa.splunk.assertions

#Data model

SplunkSearchResponse is an immutable record wrapping an ordered List<SplunkSearchResult>. It is the return type of every search/await operation on SplunkClient and the input to SplunkResponseAssert.assertThat(). In a test, it acts as the bridge between “poll Splunk until logs appear” and “assert on the log entries.” It carries helper accessors (isEmpty(), size(), first() returning Optional) but its primary role is to be the data carrier — the assertion DSL owns all the validation logic.

SplunkSearchResult is the per-row record: well-known fields (_raw, _time, source, sourcetype, host, index) plus a fields map of everything else.

#Query construction

DSL artifact Which Java-class calls Data format to input Example
.forCorrelationId() SplunkQueries — Pre-built SPL template. Produces search index=<index> correlationId="<corrId>" | spath | table correlationId, message, tracePoint, applicationName, timestamp. Overload accepts custom table field list. Keeps log field names in one place. Called internally by SplunkSupport.awaitLogsFor(); can also be called directly. String corrId + String index + optional String tableFields String spl = SplunkQueries.forCorrelationId(corrId, "mule_dev");
.search() SplunkQueryBuilder — Static entry point. Returns a new builder. — SplunkQueryBuilder.search()
.index() SplunkQueryBuilder — Appends index=<name> clause. String .index("mule_dev")
.source() SplunkQueryBuilder — Appends source=<path> clause. String .source("/opt/mule4/logs/app.log")
.sourceType() SplunkQueryBuilder — Appends sourcetype=<type> clause. String .sourceType("mule4")
.host() SplunkQueryBuilder — Appends host=<host> clause. String .host("prod-node-01")
.where() SplunkQueryBuilder — Appends field="value" clause (SPL-quote-escaped). String field + String value .where("correlationId", corrId)
.keyword() SplunkQueryBuilder — Appends a free-text keyword term (SPL-quote-escaped). String .keyword("REQUEST")
.pipe() SplunkQueryBuilder — Appends | <cmd>. Escape hatch for any pipe command (spath, rex, table, stats, etc.). String .pipe("table correlationId, message, timestamp")
.raw() SplunkQueryBuilder — Appends an unquoted search-clause fragment verbatim. String .raw("earliest=-1h latest=now")
.build() SplunkQueryBuilder — Assembles in fixed order: search → index → source → sourcetype → host → terms → pipes. — .build()

#Await — pre-assertion pipeline

DSL artifact Which Java-class calls Data format to input Example
.awaitLogsFor() SplunkSupport — Static singleton. Extracts correlationId from the ApiResponse, builds the standard SPL query via SplunkQueries.forCorrelationId(), polls Splunk until results appear. ApiResponse<?> + String index name var logs = SplunkSupport.awaitLogsFor(resp, "my_index");
.client() SplunkSupport — Returns the shared SplunkClient singleton for custom SPL queries. — var client = SplunkSupport.client();
.awaitNonEmpty() SplunkClient — Polls Splunk via Awaitility until the SPL query returns ≥1 result. Handles indexing latency. String — SPL query string client.awaitNonEmpty("search index=my_index correlationId=\"abc\"")
.awaitResults() SplunkClient — Polls until a predicate holds on the results. Generic polling with custom condition. String SPL + Predicate<SplunkSearchResponse> client.awaitResults(query, r -> r.size() >= 3)
.awaitResultsWithField() SplunkClient — Polls until at least one result has the given field=value; returns only matching results. String SPL + String field + String value client.awaitResultsWithField(query, "tracePoint", "OUT")
.searchOneShot() SplunkClient — Synchronous POST to /services/search/jobs/export. Parses NDJSON, returns SplunkSearchResponse. String SPL + optional earliest/latest time bounds client.searchOneShot("search index=my_index | head 10")
.searchBlocking() SplunkClient — Creates a search job, polls until DONE, returns results. String SPL client.searchBlocking("search index=my_index | stats count by host")

#Response-level

DSL artifact Which Java-class calls Data format to input Example
.assertThat() SplunkResponseAssert — Static entry point for Splunk search result assertions. SplunkSearchResponse SplunkResponseAssert.assertThat(logs)
.isNotEmpty() SplunkResponseAssert — Asserts the response contains at least one search result. — SplunkResponseAssert.assertThat(logs).isNotEmpty()
.hasResultCount() SplunkResponseAssert — Asserts the exact number of search results. int SplunkResponseAssert.assertThat(logs).hasResultCount(3)
.anyResultHasField() SplunkResponseAssert — Asserts at least one result in the set has a field matching the expected value. Does not navigate. String fieldName + String expectedValue .anyResultHasField("tracePoint", "IN")
.first() SplunkResponseAssert — Navigates to the first search result, returns SplunkResultAssert. Requires non-empty response. Terminal navigation — no .back(). — .isNotEmpty().first().hasField("tracePoint", "OUT")
.result() SplunkResponseAssert — Navigates to the result at a given index, returns SplunkResultAssert. Requires valid index. Terminal navigation — no .back(). int .isNotEmpty().result(1).rawContains("error")

#Per-result

DSL artifact Which Java-class calls Data format to input Example
.hasField() SplunkResultAssert — Asserts a named field equals the expected string value. String fieldName + String expectedValue .first().hasField("tracePoint", "OUT")
.fieldContains() SplunkResultAssert — Asserts a named field's value contains the given substring. String fieldName + String substring .first().fieldContains("message", "timeout")
.rawContains() SplunkResultAssert — Asserts the raw _raw field contains the given substring. String .first().rawContains("ERROR 500")
.hasSource() SplunkResultAssert — Asserts the source field equals the expected value. String .first().hasSource("/var/log/app.log")
.hasHost() SplunkResultAssert — Asserts the host field equals the expected value. String .first().hasHost("prod-node-01")

#Splunk chain invariants

  • .first() and .result() return SplunkResultAssert — terminal navigation, no .back(). Do response-level assertions (.isNotEmpty(), .hasResultCount(), .anyResultHasField(…)) before navigating into results.
  • .first() and .result() require a non-empty response — guard with .isNotEmpty().
  • SplunkSupport.awaitLogsFor(…) polls with Awaitility (default timeout 60 s, poll interval 3 s). Re-authenticates on 401 (session expiry).
  • All assertion methods extend AssertJ AbstractAssert → auto-stepped by AllureAspectJ.

#Full integration example

@Test(description = "API call produces expected Splunk logs")
public void shouldLogTracePoints() {
    var response = call("create-order", String.class)
            .bodyField("customerId", "CUST-001")
            .send();

    ApiResponseAssert.assertThat(response)
            .hasStatus(201)
            .body(b -> b
                    .field("orderId", f -> f.isNotBlank())
                    .matchesSchema("schemas/order-response.schema.json"));

    var logs = SplunkSupport.awaitLogsFor(response, "app-logs");

    SplunkResponseAssert.assertThat(logs)
            .isNotEmpty()
            .hasResultCount(1)
            .first()
                .hasField("tracePoint", "ORDER_CREATED")
                .rawContains("CUST-001");
}
